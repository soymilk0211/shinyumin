# 關於「食品業者登錄字號」

這一頁是寫給**要提供那串號碼的人**看的。不用懂電腦，看完就知道要做什麼。

---

## 一句話

**我們需要那串號碼，才能把它印在網站上。不做這件事，網站賣茶是不合規的。**

---

## 那串號碼是什麼

政府發給食品業者的**專屬編號**，像是食品業的身分證。
凡是製造、加工、販賣食品的公司，都要先去登錄才能營業。

**御茗已經有了**（老闆說有）。所以這件事**不是要重新申請、不用花錢、不用跑機關**，
只是要把那串號碼**查出來抄給我**。

號碼長得像這樣：`T-1234567890-00001`

---

## 為什麼一定要放在網站上

我們是在**網路上賣包裝好的茶葉**。

依規定，網路販售包裝食品要提供完整的中文標示與廠商資訊，**包含食登字號**。
這跟實體店面把標示貼在罐子上是同一件事 —— 只是換到網頁上。

現在網站上**完全沒有這一區**。茶葉的保存期限、保存方式、原產地、內容物
老闆都已經給我了，就差這個號碼，湊齊就能一次做完。

參考：[如何網路賣食品？該符合哪些法規](https://91app.com/blog/sell-food-online/)

---

## 不放會怎樣

會被衛生局稽查。標示不全、或登錄資料沒有維護，**罰鍰是以萬元起跳的**，
最高可以到數百萬。

參考：[食品業者登錄說明](https://startxing.com/food-fadenbook-registration-%E9%A3%9F%E5%93%81%E6%A5%AD%E8%80%85%E7%99%BB%E9%8C%84-2026/)

更實際的是：**這是被檢舉一次就會出事、但花五分鐘就能避免的事。**
網站已經做好了，卡在這一串數字上很不值得。

---

## 要做的事只有一件（大概三分鐘）

到食藥署的查詢網站：

**https://fadenbook.fda.gov.tw/home/searchlist2_2.aspx**

輸入**統一編號 `27464360`**（或公司名稱「御茗有限公司」）查詢。

查出來的那一串號碼，**抄下來或截圖**給負責網站的人就好。

> 如果查詢結果是空的，代表登錄可能沒有完成或已經失效 ——
> 那就要先處理登錄本身。這種情況請跟老闆確認一次。

---

## 拿到之後會發生什麼

網站上會多一區「食品資訊」，長得像這樣：

| 項目 | 內容 |
|---|---|
| 品名 | 各款茶葉 |
| 內容物 | 茶葉（無任何添加物） |
| 淨重 | 二兩 75g／四兩 150g／一斤 600g |
| 原產地 | 台灣 |
| 保存期限 | 兩年 |
| 保存方式 | 通風乾燥處 |
| 廠商 | 御茗有限公司．南投縣魚池鄉大雁村山楂腳巷 10-20 號 |
| 統一編號 | 27464360 |
| **食品業者登錄字號** | **← 就是缺這一個** |
| 檢驗 | 已通過 SGS 檢驗 |

做完之後，網站在食品法規上就站得住了。
