# 第 1 步：接上資料庫（Supabase）

**日期**：2026-08-17

---

## 這一步在做什麼

第 0 步蓋好了地基，這一步是**裝上檔案櫃**。

網站要記住三種東西：**有哪些茶**、**每種包裝賣多少錢**、**誰下了什麼訂單**。
這些都存在 Supabase 這個資料庫裡。

我已經把「檔案櫃的格局」寫成兩份 SQL 檔案 —— SQL 是跟資料庫溝通的語言。
您不需要看懂它，只要**複製、貼上、按 Run**。

| 檔案 | 作用 |
|---|---|
| `supabase/01-schema.sql` | 建立五張資料表，並鎖上門禁 |
| `supabase/02-seed.sql` | 放進第一筆測試商品（紅玉紅茶） |

兩份都可以重複執行，跑第二次不會弄壞任何東西。

---

## 關於「門禁」（這一步最重要的部分）

您在 HANDOVER 補的 RLS 那一條，我完全照做了。用比喻說明為什麼重要：

網站給訪客的那把鑰匙（`anon` 金鑰）**會出現在每一位訪客的瀏覽器裡，等同公開**。
稍微懂技術的人一定拿得到。

所以問題不是「怎麼藏住鑰匙」，而是**「那把鑰匙能打開哪幾個抽屜」**。

我設定的門禁是：

| 抽屜 | 訪客的鑰匙能做什麼 |
|---|---|
| 分類、商品、規格 | **只能看，不能改**，而且只看得到已上架的 |
| **訂單、訂單明細** | **完全打不開** —— 顧客的姓名、電話、地址一個字都讀不到 |

訂單一律由**伺服器**用另一把萬能鑰匙（`service_role`）處理，
那把鑰匙只存在您電腦上的 `.env.local` 檔案與日後 Vercel 的設定裡，永遠不會進到瀏覽器。

這一步結束時會跑一支健檢程式，**實際嘗試用訪客鑰匙去偷讀訂單、去改價格**，
確認真的被擋下來。

## 請您操作（大約 10 分鐘）

### ① 建立資料表

1. 打開 https://supabase.com/dashboard ，進入 **`shinyumin-web`** 這個 project
2. 左邊選單點 **SQL Editor**
3. 點 **New query**（或 `+` 號）
4. 打開電腦上的檔案 `C:\Users\user\Projects\tea-brand-ecommerce\supabase\01-schema.sql`，
   **全選、複製**，貼到剛剛那個空白的輸入框
5. 按右下角的 **Run**（或 `Ctrl + Enter`）

看到綠色的 **Success. No rows returned** 就是成功了。

### ② 放進測試商品

1. 再點一次 **New query**
2. 這次複製 `supabase/02-seed.sql` 的全部內容，貼上
3. 按 **Run**

同樣看到 Success 就好了。

### ③ 看一眼成果

左邊選單點 **Table Editor**，應該會看到五張表：

- `categories`（3 筆：紅茶、烏龍茶、綠茶）
- `products`（1 筆：紅玉紅茶）
- `variants`（2 筆：150g $650、75g $380）
- `orders`（0 筆，還沒有人下單）
- `order_items`（0 筆）

每張表的名字旁邊應該都有一個**綠色的 RLS enabled** 標示。

### ④ 拿鑰匙，建立 `.env.local`

1. 左邊選單最下面 **Settings** → **API Keys**（或 **API**）
2. 這一頁上有兩把鑰匙。Supabase 這一兩年改過命名，您看到的可能是任一組：

   | 我需要的 | 舊版名稱 | 新版名稱 |
   |---|---|---|
   | 公開的那把 | `anon` `public` | **Publishable key**（`sb_publishable_...` 開頭） |
   | 秘密的那把 | `service_role` `secret` | **Secret key**（`sb_secret_...` 開頭） |

3. 在專案資料夾開啟終端機，執行這一行，複製出一份設定檔：

```bash
copy .env.example .env.local
```

4. 用記事本打開它：

```bash
notepad .env.local
```

5. 把兩把鑰匙分別貼在 `=` 後面（不要有空格、不要加引號），存檔關閉。

> ⚠️ **請不要把 `service_role`／Secret 那把鑰匙貼進我們的對話視窗。**
> 那把鑰匙可以繞過所有門禁，等於資料庫的萬能鑰匙。
> 它只需要待在 `.env.local` 這個檔案裡 —— 那個檔案已經被設定為**不會上傳到 GitHub**。
> 我不需要看到它的內容也能完成後續工作。

### ⑤ 執行健檢

在同一個終端機執行：

```bash
npm run check:supabase
```

**預期看到**：一連串 ✅，最後一行是

```
🎉 全部通過。資料庫已經接好，而且門禁是鎖上的。
```

如果有任何 ❌，**把整段訊息複製貼給我**，我來處理。
這支程式只會印出通過／失敗，不會印出您的鑰匙內容，所以貼過來是安全的。
