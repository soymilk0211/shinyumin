# 第 2 步（改版）：編輯式非對稱排版

**日期**：2026-08-17

---

## 為什麼重做

第一版的排版是「置中對齊的整齊網格 + 冷色紫藍」。那是軟體介面的長相，
不是一個有文化底蘊的家族茶品牌該有的樣子。業主的指示很明確：
獨立雜誌與高端藝術展覽等級的非典型排版。

這一版是照那份指示重做的。

---

## 設計方案

動手寫程式之前先定下的三件事：

### 色彩：侘寂

| | 淺色模式 | 深色模式 |
|---|---|---|
| 底色 | 宣紙米灰 `#ebe5d8` | 炭焙黑 `#131110` |
| 文字 | 墨 `#201b14` | 米白 `#efe9dc` |
| 重點色 | 茶湯琥珀 `#8a5417` | 茶湯琥珀（提亮）`#d6a05e` |

**黑刻意帶暖調，不是藍黑。** 純黑與藍黑在螢幕上很銳利、很「科技」；
炭焙茶葉的黑其實偏褐。用暖黑，紙感與茶感才對得起來。

琥珀在深色模式必須提亮，否則會沉進背景裡看不見 —— 同一個顏色在不同底色上
需要不同的明度，這是必要的補償，不是兩套顏色。

**全部集中在 [`src/app/theme.css`](../src/app/theme.css)**，改色只需要動那一個檔案。

### 字體：極致的比例對比

- **標題**：Noto Serif TC（繁體明體），只用一種字重
- **內文**：極小（12–13px）、字距拉寬、行高拉到 2.1 倍

首頁主標題在手機上 52px、在電腦上 166px。這種「巨大標題 + 極小內文」的
對比就是編輯式設計的骨架 —— 層次靠**字級**與**留白**拉開，不靠粗體。
所以全站的標題都是細的，沒有一個字是粗體。

### 佈局：打破網格

- 沒有置中的容器，內容從版面左緣算起
- 首頁開場：巨大標題與右側出血的圖**刻意重疊 48px**
- 五道工序排成往右下走的**階梯**，不是整齊的五等分
- 紅玉那一段：文字塊往左壓進圖裡，並且往下錯開
- 分類三格**高低錯落**，刻意不對齊
- 左緣的地名用**直式排版**（`writing-mode: vertical-rl`）

### 反傳統的 UI 元件

按鈕全部拿掉了。取而代之的是：極小的字、拉寬的字距、一支細箭頭，
滑鼠移上去時底線由左往右展開、箭頭往前走一小步。
互動感來自「動作」，不是來自「框」。

## 真實內容

版面上不再只有空洞的佔位符。實際的產品資訊被編進版面的細節裡：

- **台茶 18 號 / RUBY No.18** —— 開場右下角的浮動標記
- **紅玉紅茶**、台灣野生山茶 × 緬甸大葉種
- **150g 真空罐裝　NT$ 650** —— 用細線表格呈現，不是價格標籤
- 五道工序：採菁、萎凋、揉捻、發酵、乾燥，每一道配一句實際的說明

> 這些目前還是寫在程式裡的。第 3 步會改成從資料庫讀，
> 屆時您在後台改價格，網站上就會跟著變。

## 深淺色會跟著手機的設定走嗎

**會。** 訪客第一次進來時，網站直接採用他手機／電腦的系統設定 ——
手機開了深色模式就是炭焙黑，沒開就是宣紙米灰。

如果訪客自己按了右上角的月亮／太陽，那就以他按的為準，
而且這個選擇會記在他的瀏覽器裡，下次再來還是同一個。

## 過程中發現並修掉的問題

這些都是實際量測出來的，不是憑感覺：

1. **字型太肥（1.4MB）**：原本抓了三種字重。中文字型每一種字重都是一份完整的
   字型檔，手機用 4G 開會有感。改成只用一種字重，降到約 830KB。
   這個設計本來就靠字級拉層次、不靠粗細，一種字重完全夠用。

2. **手機上工序被擠成細長條**：階梯縮排在 375px 寬的螢幕上，
   到第五階時說明文字只剩 74px 寬。改成手機不縮排、說明另起一行，
   階梯效果留給平板與電腦。

3. **手機上說明文字壓在圖上**：開場的圖原本用絕對定位浮在右側，
   在窄螢幕上會蓋到文字。改成手機排在標題下方（向右出血），
   電腦上才浮起來與標題重疊。

4. **最淡的灰看不見**：`#a19683` 在宣紙底上的對比只有 2.2:1，
   11px 的小標籤在手機上、尤其白天戶外幾乎看不見。調深到約 3.3:1。
   頁尾的地址、電話、統編改用最清楚的墨色 —— 那些是客人真的要看的資訊。

5. **英文站的直式文字每個字母都直立**：改成 `text-orientation: mixed`，
   中文字直立、英文與數字側轉 90 度，這是中日文直排的標準作法。

檢查結果：`npm run lint` 與 `npm run build` 通過，瀏覽器主控台無錯誤，
375px 與 1280px 都沒有水平溢出，網頁原始碼中查不到任何 email 格式字串。

## 還沒解決、值得知道的一件事

**中文字型 830KB，第一次開網站時要下載。**

不會白屏 —— 文字會先用手機內建字型顯示，明體下載完成後再換上去。
但在慢一點的網路下，前一兩秒看到的字會不是最終的樣子。

未來如果覺得這一兩秒不能接受，有一個作法是：自己做一份「只包含網站用到的字」
的精簡字型檔，可以壓到 50KB 以內。但那份檔案是寫死的，
第 3 步之後商品名稱改由您在後台維護，一改字就可能缺字。
所以這件事建議等商品內容穩定下來再做。
