# 部署到 Vercel：讓網站有一個真的網址

**日期**：2026-08-17

---

## 為什麼要做這件事

到目前為止，您看到的都是我做的**靜態快照** —— 版面看得到，但轉盤不會轉、
連結不會跳、加入購物車按不了。

部署之後您會拿到一個真的網址（像 `shinyumin.vercel.app`），
用手機隨時打開就是**完整的網站**：轉盤會轉、可以點進商品、可以加入購物車。

而且之後**我每次 push，網站會自己更新** —— 我改完跟您說一聲，
您重新整理就看得到，不用再等我做快照。

> 這個網址是**測試用**的。正式的網域（您自己的那個）等確認狀況後再接上。
> 在那之前，網站已經設定成**不讓 Google 收錄**（見下面說明）。

## 請您操作（大約 10 分鐘）

手機或電腦都可以做。

### ① 註冊／登入 Vercel

到 **https://vercel.com** ，選 **Continue with GitHub** 用 GitHub 帳號登入。

> 一定要用 GitHub 登入，Vercel 才看得到 `shinyumin` 這個專案。

### ② 匯入專案

1. 右上角 **Add New…** → **Project**
2. 清單裡找到 **`soymilk0211/shinyumin`** → 按 **Import**
3. Framework 那一欄會自動顯示 **Next.js**，不用改任何設定

### ③ 填四個環境變數（**這一步最重要**）

在 Import 的畫面展開 **Environment Variables**，一個一個加：

| Name | Value |
|---|---|
| `NEXT_PUBLIC_SUPABASE_URL` | `https://pemiinvmlwbotmzzszpz.supabase.co` |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY` | Supabase → Settings → API Keys 的**公開**金鑰 |
| `SUPABASE_SERVICE_ROLE_KEY` | 同一頁的**秘密**金鑰 |
| `NEXT_PUBLIC_ALLOW_INDEXING` | `false` |

這四個跟您電腦上 `.env.local` 裡的是同一組（最後一個是新的）。

> ⚠️ 秘密金鑰請直接貼在 Vercel 的欄位裡，**不要貼進我們的對話**。
> Vercel 會加密保存，不會出現在網址或網頁原始碼裡。

沒填的話網站還是會開，但看不到商品（會顯示「商品正在整理中」）。

### ④ 按 Deploy

等 1–3 分鐘。完成後會出現一個網址，長得像 `shinyumin.vercel.app`。
**把那個網址貼給我**，我幫您檢查每一頁是否正常。

## 部署完成後，還有三個設定要做

### 1. 機器區域改成新加坡（速度差很多）

> ⚠️ **2026-08-18 更正：資料庫其實在東京，不是新加坡。**
> 所以這裡比較好的選擇是 **Tokyo (hnd1)**，讓網站主機跟資料庫在同一區，
> 每一次查資料就少繞一趟。目前設成新加坡也能用，只是每個資料庫查詢
> 多幾十毫秒 —— 不急著改，但下次進 Vercel 設定時可以順手調。

**Settings → Functions → Function Region**，若清單裡有
**Singapore (sin1)** 就選它。

預設是美國華盛頓。我們的資料庫在新加坡、客人在台灣，
機器留在美國的話，每次讀商品都要繞地球一圈。

### 2. 設定花費上限（重要）

**Settings → Spend Management**：設一個您能接受的上限（例如 US$5），
並開啟**超過就自動暫停**。

Vercel 超量之後是**沒有上限的計費**，這一道是保險。

### 3. 收錢之前必須升級 Pro

Vercel 免費方案（Hobby）**禁止商業用途**。現在是測試階段沒問題，
但**開始接受訂單收錢之前必須升級 Pro（US$20／月）**。這在 HANDOVER 的地雷清單裡。

## 為什麼現在不讓 Google 收錄

網站上的照片都還是佔位符、文案也還沒定稿。
這種狀態被 Google 抓進去，**日後就算改好了，搜尋結果也可能還顯示舊的、
不完整的內容一段時間** —— 那是別人搜尋「御茗」時的第一印象。

所以程式裡加了一道開關：`NEXT_PUBLIC_ALLOW_INDEXING`。
現在設 `false`，網頁會告訴搜尋引擎「請不要收錄」。

內容都定稿、要正式對外的時候，把它改成 `true` 就好 ——
**改一個設定值，不需要改程式、不需要我重新部署。**
