# 第 11 步：公告橫幅

## 一句話

**網站每一頁的最上面可以掛一行公告，你在手機後台打字、按一下就出現，
到了設定的日期會自己收起來。**

---

## 為什麼做這個

老闆的政策是「**價格要調整前先公告一個月**」。

系統**刻意不做「排程自動改價」**（設定好時間、時間到了自己變價格）——
那種東西出錯的時候，錯誤會發生在半夜、沒有人在看，
而且改錯的是「錢」。改價維持人工，你按了才會變。

但「公告」這一半可以自動：打好字、設一個結束日期，
時間到它自己收，不用記得回來關。

---

## ⚠️ 你要先做一件事（大概一分鐘）

跟之前設定付款方式、會員那兩次一樣，要先去資料庫建一張放公告的表。

1. 打開這份 SQL：
   **https://github.com/soymilk0211/shinyumin/raw/main/supabase/05-announcement.sql**
2. **整份複製**
3. 貼到 Supabase 的 SQL Editor，按 **Run**

沒做這一步的話，後台的公告那一頁會告訴你「還差最後一步」，
**網站其他地方完全不受影響**，照常運作、照常收單。

---

## 怎麼用

後台首頁（訂單那一頁）最上面多了一個「**公告**」的連結。

裡面有三塊：

### 一、目前狀態

一眼看出客人現在看不看得到。旁邊是**開關**：
「開始顯示」／「從網站上收起來」。

### 二、客人會看到的樣子

**這就是客人實際會看到的畫面**，不是示意圖 ——
用的是網站上同一個元件，所以看到什麼就是什麼。

### 三、編輯

- **公告內容（中文）**：一句話就好，最多 200 字
- **英文版（選填）**：留空白也可以，英文站會顯示中文那一段
- **公告到哪一天（選填）**：到了隔天自動收起來。空白 = 一直顯示

---

## 【重要】存檔不等於公開

這兩件事**刻意分成兩個按鈕**：

| 按鈕 | 會發生什麼 |
|---|---|
| **儲存** | 只是把字存起來。**客人看不到。** |
| **開始顯示** | 這時候客人才看得到 |

**為什麼要分開**：你很可能會想「先把下個月的漲價公告打好放著，時間到再開」。
如果存檔就等於上線，那手一滑，還沒定案的價格就公告出去了 ——
而且是公告給所有人看。

（還沒打字之前，「開始顯示」是按不下去的，不會出現一條空白的橫幅。）

---

## 怎麼驗證

1. 進後台 → 公告
2. 內容打「**測試公告，等一下會刪掉**」
3. 按 **儲存** → 這時候去前台看，**應該還是沒有**（這是對的）
4. 回後台按 **開始顯示**
5. 去前台重新整理 → 最上面出現那一行字
6. 回後台按 **從網站上收起來** → 前台重新整理，橫幅不見了

> 前台的頁面為了跑得快會暫存最多一分鐘，但按開關的時候程式會主動去更新，
> 所以正常情況下重新整理就會看到。萬一沒看到，等一分鐘再重整一次。

**日期的驗證**：把「公告到哪一天」設成**昨天**再儲存，
前台就會看不到了（後台會顯示一行紅字告訴你日期已經過了）。

## 寫給工程面的（業主不用看）

| 檔案 | 做什麼 |
|---|---|
| `supabase/05-announcement.sql` | 資料表與門禁。**業主要自己跑** |
| `src/lib/announcement.ts` | 前台讀公告（公開金鑰） |
| `src/lib/admin-announcement.ts` | 後台讀寫（service_role） |
| `src/components/site-announcement.tsx` | 橫幅長什麼樣子。前台與後台預覽共用同一個 |
| `src/app/admin/announcement/page.tsx` | 後台那一頁 |
| `src/app/admin/actions.ts` | 加了 `saveAnnouncement` 與 `toggleAnnouncement` |
| `src/app/[locale]/layout.tsx` | 把橫幅掛在選單列上面 |

幾個當初的判斷，日後要改的人先看一下：

- **「該不該顯示」只判斷一次，判斷在資料庫的 RLS 裡。**
  沒在顯示、或已經過期的公告，訪客用公開金鑰**連讀都讀不到** ——
  因為業主會先把下個月的漲價公告存著，那段文字在打開之前不該外流。
  程式端不再判斷第二次：日期判斷兩遍，兩邊時區只要有一邊寫錯，
  就會變成「有時候顯示、有時候不顯示」的鬼故事。

- **RLS 裡的日期一定要寫明台灣時間**（`now() at time zone 'Asia/Taipei'`）。
  資料庫的機器跑在 UTC，直接用 `current_date` 會比台灣慢八小時。

- **資料表不存在時要安靜地回 null。** 程式會比業主去貼 SQL 先上線，
  這段期間網站要照常運作，而且不能每開一頁就在記錄檔裡吼一次。
  後台那一頁則要顯示「下一步做什麼」，不是丟一串英文錯誤給業主。

- **橫幅那一列不可以換行。** 允許換行的話，手機上「公告」兩個字
  會被擠到自己一行，橫幅從 47px 長到 91px，商標與選單全被往下推。
  （已量過：改成不換行之後手機上是 70px。）

- **不做「關閉」按鈕。** 關掉要記在瀏覽器裡，就多一份儲存、
  多一個伺服器與瀏覽器對不起來的閃爍。公告有結束日期會自己收。

- 對比度量過：淺色 5.28:1、深色 6.52:1，都超過 4.5:1 的標準。
